# Étude+ Android

Application Android native Java sans HTML.

## APK
Dans GitHub Actions, ouvrir « Construire APK Android » et récupérer l'artifact `EtudePlus-APK` après compilation.

Prototype : trois matières, quatre niveaux de navigation, consignes vocales, toucher ou glisser-déposer. Les exercices ne sont pas encore adaptés à chaque niveau. Aucun compte requis.
